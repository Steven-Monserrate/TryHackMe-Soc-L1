#Cyber Kill Chain

#Notes:

#Kill Chain – A military concept related to the structure of an attack. It consists of target identification, decision and order to attack the target, 
#and finally the target destruction

#Reconnaissance – The research and planning phase of an attack against a system or victim

#OSINT (Open-Source Intelligence) – Using publicly available resources, like search engines, media, social media, etc. to gain information about a target

#Types of Reconnaissance
  #Passive – Involves having no direct action with the target. May include WHOIS lookups, social media scraping, or reviewing breach data
  #Active – Involves direct contact with the target. May include social engineering, port scanning, banner grabbing, or probing for open services

#Email harvesting – The process of obtaining email addresses from public, paid, or free services
  #Commonly includes:
    #theHarvester
    #Hunter.io
    #OSINT Framework

#Malware – A program or software that is designed to damage, disrupt, or gain unauthorized access to a computer

#Exploits – Programs or code that take advantage of the vulnerability or flaw in the application system

#Payload – A malicious code that the attacker runs on the system

#Macro – An automated script embedded in Microsoft Office documents that can be used to perform tasks or exploited by attackers for malicious purposes

#Exploitation – The moment that the attacker’s code executes on the target, taking advantage of a known vulnerability

#Web Shell – A malicious script written in web development programming languages such as ASP, PHP, or JSP used by an attacker to maintain access to the compromised system

#Meterpreter – A Metasploit Framework payload that gives an interactive shell from which an attacker can interact with the victim’s machine remotely and execute the
#malicious code

#T1543.003 – Creates or modifies Windows services

#Timestomping – Lets an attacker modify the file’s timestamps, including to modify, access, create, and change times

#C&C/C2 Beaconing – Command and Control channel is accessed through malware to remotely control and manipulate the victim

#Shadow Copy – A technology included in Microsoft Windows that can create backup copies or snapshots of files or volumes on the computer, even when they are in use
